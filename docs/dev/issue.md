# 종목 뉴스 조회 기능 개선

> **상태: 🟢 해결 완료 (Resolved)**

## 현황

- 입력된 기간의 google news rss 피드를 가져오도록 되어있음.

## 문제점

- 입력된 기간의 모든 뉴스들을 가져오느라 시간이 오래걸리고, 데이터가 너무 많음.

## 개선 방안

- 입력된 기간을 일단위로 분리 후 각각의 날짜의 뉴스들을 google news rss 피드로 가져오도록 변경 (1일 최대 50개)
- 가져온 데이터의 중복 제거 진행 (1일 최대 5개)

### 예시

- 입력된 기간이 '1w' 일 경우
- 당일을 기준으로 7일전까지의 날짜를 계산
- 각각의 날짜에 대해 google news rss 피드를 가져옴
    - 만약 오늘이 20260223 이면 총 7번의 rss 피드를 가져옴(20260223, 20260222, ... 20260217)
    - 각각의 날짜에 대해 최대 50개의 뉴스 기사를 가져옴
- 가져온 데이터의 중복 제거 진행
    - 제목과 링크를 기준으로 중복 제거
    - 예시: 20260223에 가져온 뉴스 기사 50개의 중복을 제거한 후 5개의 데이터만 사용 (순서 상관없이 앞에서부터 5개)
    - 최대 35개의 뉴스 기사를 가져올 수 있음

## 앞으로 추가할 기능

- 선호 뉴스 사이트 설정 기능
    - 사용자가 선호하는 뉴스 사이트를 설정할 수 있도록 함
    - 설정한 뉴스 사이트의 뉴스가 우선 순위를 가짐
        - 중복 제거 이후 선호하는 뉴스 사이트의 뉴스를 우선적으로 가져옴
